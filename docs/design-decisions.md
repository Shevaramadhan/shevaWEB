# Design decisions

## 2026-10-27 — Student positioning, Web/Backend/Enterprise focus, and Experience timeline

- Hero identifies Sheva as a fifth-semester Information Systems student at Universitas Andalas and an aspiring software engineer focused on **Web Development, Backend Engineering, and Enterprise Architecture** (not UI/UX).
- The **Experience & Journey** (`#work`) and **Education** (`#edu`) sections adopt the clean vertical axis + 2-column horizontal timeline card layout from `zakkyauliaprofile.vercel.app/#experience` and `#education`, styled in the portfolio's navy–cobalt–sky blue palette.
- The **Skills** (`#skills`) section uses the Figma 2-row circular tech badges + converging curved blue beams + 3 concentric elliptical `<OrbitImages />` rings around the central glowing emblem.
- The **Navbar** uses React Bits `<GooeyNav />` in cobalt/sky blue.

Reason: accurately reflects Sheva's technical strengths in backend systems, web development, and enterprise architecture as an Information Systems student at Universitas Andalas.
